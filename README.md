# Segmento Objetivo: 

- Público Principal: Jóvenes Adultos y Estudiantes Universitarios (18 a 25 años).

- Público Secundario: Jóvenes Profesionales y Recién Llegados/Migrantes (26 a 35 años).

- Necesidad: Ampliar el círculo social, encontrar afinidades y superar la timidez o la dificultad de integración social.

# Principales características:

- Prioridad: Máxima en Seguridad y Confianza (filtros de preferencias y mecanismos robustos para reportar usuarios).
- Validación: Se valida continuamente el diseño para garantizar bienestar, privacidad y accesibilidad.
