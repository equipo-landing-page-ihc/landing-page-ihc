# Segmento Objetivo: 

1. Jóvenes Adultos y Estudiantes Universitarios
   - Edad: 18 – 25 años
   - Características: Personas en etapa de formación personal y profesional, alto uso de redes sociales y tecnología, buscan ampliar su círculo social y explorar nuevas actividades.
   - Necesidades: Conectar con personas con intereses similares, integrarse a nuevos grupos o comunidades, encontrar amistades genuinas fuera de su entorno habitual.
   - Motivaciones: Sentirse parte de una comunidad, compartir hobbies y experiencias, expandir su red social y crear amistades auténticas.
2. Jóvenes Profesionales y Recién Llegados a una Ciudad
   - Edad: 25 – 35 años
   - Características: Profesionales con movilidad geográfica debido a estudios o trabajo, poco tiempo para socializar, dificultades para integrarse socialmente en un nuevo entorno.
   - Necesidades: Encontrar amistades de manera rápida y segura, reducir la sensación de soledad, crear conexiones más allá del entorno laboral.
   - Motivaciones: Construir una red social significativa, adaptarse emocional y socialmente a la nueva ciudad, sentirse acompañados en el proceso de cambio.

# Principales características:
- Necesidad que cubre: Facilitar la expansión del círculo social, conectar con personas afines y ayudar a usuarios con timidez o dificultades para integrarse socialmente.
- Privacidad activa: Control total sobre qué información se comparte y con quién.
- Validación continua: El diseño se evalúa de forma constante para asegurar bienestar, privacidad y accesibilidad.
- Personalización: El usuario puede ajustar preferencias para recibir recomendaciones más relevantes.
- Experiencia intuitiva: Interfaz sencilla y fácil de usar que minimiza la curva de aprendizaje y evita complicaciones.
- Retroalimentación constante: El sistema aprende de las acciones del usuario para mejorar la experiencia con el tiempo.
